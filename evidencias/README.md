# 📸 Carpeta de Evidencias e Imágenes

En esta carpeta podés guardar las capturas de pantalla y fotos de prueba del funcionamiento de **Botiquín al Día**.

## 📂 Nombres sugeridos para tus capturas

Para mantener el proyecto prolijo y que se muestren automáticamente en los Readme, te recomendamos usar estos nombres de archivo:

1. **`01-registro-producto.png`**  
   *Captura del formulario modal donde se ingresa el nombre, la cantidad y la fecha de vencimiento con los atajos rápidos.*

2. **`02-panel-alertas.png`**  
   *Captura de la pestaña de Alertas con medicamentos vencidos (en rojo) y los que vencen en los próximos 30 días (en naranja).*

3. **`03-lista-reposicion.png`**  
   *Captura de la lista de compras para la farmacia con el botón de copiar para WhatsApp y checkboxes de comprado.*

4. **`04-vista-movil.png`**  
   *Captura de la pantalla completa vista desde un teléfono celular (diseño responsive touch-first).*

## 🖼️ Cómo insertar una imagen en tus archivos Markdown

Una vez que guardes tu imagen en esta carpeta, podés enlazarla en cualquier archivo `.md` así:

```markdown
![Registro de Producto](./evidencias/01-registro-producto.png)
```

O si querés centrarla y ajustar el tamaño:

```html
<p align="center">
  <img src="./evidencias/01-registro-producto.png" alt="Registro de Producto" width="380" />
</p>
```
